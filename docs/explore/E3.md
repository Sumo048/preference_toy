## Headline

**Recipe knobs barely matter. The data mask decides the outcome.** No parameter subset, adapter, anchor variant,
anchor weight, learning rate, or training length moves B1a by more than about 0.015 in D, except the variants that
make it worse. A privileged oracle (BC on 20,000 π_ref samples of retained modes, labelled by `CondMixture.assign`)
reaches D 0.037 at 5k steps and 0.025 at 20k. So the headroom below B1a (0.34 on these cells) is about 0.31 in D.

**A label-free method closes all of that gap: track-masked BC.** Cluster π_ref's own decodes on a grid of 101
conditions. Link the clusters across neighbouring conditions into behaviour tracks. Each logged negative marks its
track as bad. Then fine-tune on π_ref's anchor samples whose track is not bad (fresh noise, flow-matching loss).
It reads only π_ref decodes, network inputs, and the logged negatives: no labels, no ring geometry, and no mode count.

- Seeds 0–4, npm 4 and 16 (20 cells): D **0.039** (5k steps, 20k-sample pool) and **0.030** (20k steps,
  60k-sample pool), against B1a 0.363 and B0 0.515. It is lower than B1a in 20 of 20 cells. Removed 0.98–0.99,
  Collateral 0.016–0.018.
- It matches or beats the oracle BC (0.038 at the same budget), because the track mask also drops
  atypical, between-mode samples (mass_off 0.012–0.024, against 0.027 for π_ref).
- It holds at npm 1, with one negative per forgotten mode: D 0.032 against B1a 0.48. It also holds at npm 64.
  One negative per forgotten mode labels the whole track, so npm 4 and npm 16 give identical masks.

## Why it works

1. **B1a's anchor mask is wrong in `alt`, and that drives its Collateral.** The toypref vote flags a noise ξ by
   decoding it at every negative's condition. It ignores the anchor sample's own c. The ring rotates by 1.5 mode
   spacings over c, so a noise region that is bad at one condition is a retained mode at another.
   `diag_vote.py` (oracle used only to score) shows the effect. On `alt` s0 the vote flags 84–90% of the anchor pool
   at 0.49–0.51 precision, which is chance. The kept anchor set then has retained mode shares of
   0.012 / 0.288 / 0.261 / 0.061 instead of 0.25 each. The anchor teaches that imbalance, which gives retain TV 0.30.
   On `k4` the vote precision is 0.73–0.75. The track mask has precision 1.00 in all 20 cells (recall 0.84–0.89 on the 4
   cells of `diag_vote.json`; the misses are atypical samples, which the track mask drops anyway). The kept set holds at most 1.2% bad samples.
2. **A behaviour is continuous in c in action space, even though the noise→behaviour map is not stable across c.**
   π_ref has 8 well-separated clusters at every grid condition (8–10 with fragments), and the mutual-nearest
   centroid links between neighbouring grid points never jump between behaviours. The 8 big tracks were 100% pure
   on every cell checked.
3. **With a correct mask, the edit is plain density BC.** The rerouting term then hurts: adding B1a's rerouting rows
   to the track anchor (`a=track`, w 0.5) gives 0.085, and w 0.75 gives 0.060, against 0.032 without rerouting.
   A likely cause: rerouting sends each negative's noise to the nearest other basin, which biases mass towards
   neighbouring modes (not measured separately).
   The same holds with the oracle mask (`a=omask` 0.088 against `a=omask-w=1` 0.038). This is not a
   label-quality effect.

## Edit size and parameter subsets

With the track data, a rank-4 adapter (8.7k trainable parameters, 5% of the network) is enough: D 0.034 against
0.032 for full fine-tuning. One residual block reaches 0.196 (`p=b2`). The output layer or the head alone
cannot do it
(0.41–0.42). 1,000 steps at lr 1e-4 reach 0.244, and 1,000 steps at lr 3e-4 reach 0.050. Weight-change Frobenius norm:
B1a 10.4, track BC 7.2 (5k steps), and track BC with LoRA-4 16.9 (low rank, larger norm). Full fine-tuning changes
every weight. Train time on one CPU thread: B1a about 120 s, track BC about 63 s, track build under 1 min
(51,712 decodes).

## Which measurements made the edit easy to design (candidate Phase 4 tools)

1. **Behaviour tracks across c** (`tracks.py`): the number of clusters per condition, the track count and
   purity proxy (sizes), which tracks a cluster's negatives hit, and each sample's track id. This turns
   a few logged negatives into a dense, condition-consistent bad/good partition of π_ref's own samples. A
   `tracks(cluster)` tool and a `track_mask` data option for `targeted_train` would give the surgeon this directly.
2. **Mask-quality check without labels:** the balance of the kept anchor set across tracks (shares per kept track).
   A healthy mask keeps the retained tracks equal. The vote mask's imbalance (0.012 against 0.288) is visible
   without any oracle.
3. **The knob sweep itself:** steps, lr, subsets, and anchors all sit within ±0.015 of B1a. So a surgeon should spend
   its budget on the training data, not on the optimizer.

## What failed or did not help

- Every B1a knob: LoRA 4/16, one block (b0/b1/b2), all fc2, 20k steps, lr 3e-4, anchor weight 0.75,
  vote over 20k samples (`a=dist20k`), mined negatives (`m=1`): all within +0.015/−0.002 of B1a.
- Unmasked anchor (`a=full`): Collateral drops to 0.07 but Removed falls to 0.23 (D 0.411). Local anchor (0.388) and
  map anchor (0.370) are also worse.
- Training only `out`, `head`, or the condition MLPs: D 0.42–0.48. Track data does not rescue `out` or `head` either.
- B1a is worse than B0 in 1 of 10 `alt` cells.

## Caveats

- `a=track-w=1-on=map` duplicates `a=track-w=1`: the `on` key applies only to `o=1`. It is listed for completeness.

- Tracks rely on π_ref's behaviours forming separated clusters at each condition, which holds in this toy (mode std
  0.25, spacing about 2). Overlapping behaviours, or behaviours that split or merge along c, would break the
  linking. Merged tracks would flag retained samples.
- This is a global edit on all negatives at once (gate global scope), not a per-cluster repair. The per-cluster
  version is the same mask restricted to the cluster's tracks.
- Exploration on development seeds, outside the claims (Amendment 1). Nothing here changes the gate, the thresholds,
  or the surgeon's static prompt.
