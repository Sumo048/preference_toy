# E2: direction edits (exploration, outside the claims)

Session E2, 2026-11-03/04. Seeds 0–4 only; cells `k4` (n_forget 4, random) and `alt` (n_forget 4, layout alt),
npm 4 and 16. Code: `explore/E2/`. Per-cell results: `explore/E2/results/<cell>/<method>.json`.
B0 and B1a (`R_hopB_bsup_neg_AMdist`) come from `scripts/cond_cell.py` on the same cells (`explore/E2/run_baselines.sh`).

**Metrics.** D = `tv_to_ideal`, Removed = 1 − `neg_mass_ratio`, Collateral = `retain_tv` (TV over retained
modes, renormalised; the closest key `compute` returns), off = `mass_off` (mass between modes), all from the
repo's `experiment.compute` on the cell's eval bank. The oracle is used only there and in printouts marked ORACLE.

**What the edits read.** Every deployed edit reads only network inputs (x, t, c) and activations. Edit design
uses only label-free data: the logged negatives, π_ref's basins at their conditions (`targets.basins_at`), the
vote, and the miner affinity of PLAN 6.2. Every trained edit is fit with **the frozen recipe's own loss and
data** (hopB targets, basin support, vote-masked dist anchor; `experiment.step_fn`), with π_ref's weights
frozen and only the edit's parameters trained (Adam, lr 1e-2, 2,000 steps). So B1a and an edit differ only in
the structure of the change, unless the method name says otherwise (`_w`, `_a`).

## Method names

| Name | Edit |
|---|---|
| `r1_<layer>[_r<k>]` | rank-k update W ← W + Σ u_i v_iᵀ (+ bias term u_i β_i) on `out`, `fc2.j` or `fc1.j`; u, v, β learned |
| `r1_fc2.0+fc2.1+fc2.2_r4` | rank-4 updates on all three blocks' `fc2` at once (3,084 parameters; the net has 163,458) |
| `_t<lo>-<hi>` | t-gate: the edit acts only for t ∈ [lo, hi] (t = 1 noise, 0 action); `t0.4-1` = the first 60% of the decode |
| `r1p_<layer>` | rank-1 with v fixed to one global contrast-probe direction; u, β learned |
| `r1pc_<layer>` | one rank-1 per miner cluster, v fixed to that cluster's contrast-probe direction; u, β learned |
| `r1pcg` / `r1pcx` / `r1pcgx` | as `r1pc`, with a one-sided read u·relu(vᵀa+β) (`g`, a 1-unit graft: E1's family) and/or the probe calibrated against good trajectories at every negative's condition (`x`) |
| `abl_<site>` | mean-ablate the global probe direction (`ablate_direction`, side post) |
| `ablc_<site>` | mean-ablate all per-cluster mean-difference directions |
| `_w1-<b>` | loss = (hopB method + 1·vote-masked dist anchor + b·local anchor) / (2 + b); `w1-0` = B1a's loss |
| `_aAML` | the repo's `AML` anchor (local + vote-masked, logged noise) in place of `AMdist` |
| `b1a_trunc_r<k>` | train B1a (all weights), then keep only the top-k singular directions of each weight matrix's change |
| `full_w1-0.5` | control: all weights trained with the `_w1-0.5` loss and B1a's schedule |
