# E2: direction edits (exploration, outside the claims)

Session E2, 2026-11-03/04. Seeds 0–4 only; cells `k4` (n_forget 4, random) and `alt` (n_forget 4, layout alt),
npm 4 and 16. Code: `explore/E2/`. Per-cell results: `explore/E2/results/<cell>/<method>.json`.
B0 and B1a (`R_hopB_bsup_neg_AMdist`) come from `scripts/cond_cell.py` on the same cells (`explore/E2/run_baselines.sh`).

**Metrics.** D = `tv_to_ideal`, Removed = 1 − `neg_mass_ratio`, Collateral = `retain_tv` (TV over retained
modes, renormalised; the closest key `compute` returns), off = `mass_off` (mass between modes), all from the
repo's `experiment.compute` on the cell's eval bank. The oracle is used only there and in printouts marked ORACLE.

**What the edits read.** Every deployed edit reads only network inputs (x, t, c) and activations. Edit design
uses only label-free data: the logged negatives, π_ref's basins at their conditions (`targets.basins_at`), the
vote, and the miner affinity of PLAN 6.2. Every trained edit is fit with **the frozen recipe's own loss and
data** (hopB targets, basin support, vote-masked dist anchor; `experiment.step_fn`), with π_ref's weights
frozen and only the edit's parameters trained (Adam, lr 1e-2, 2,000 steps). So B1a and an edit differ only in
the structure of the change, unless the method name says otherwise (`_w`, `_a`).

## Method names

| Name | Edit |
|---|---|
| `r1_<layer>[_r<k>]` | rank-k update W ← W + Σ u_i v_iᵀ (+ bias term u_i β_i) on `out`, `fc2.j` or `fc1.j`; u, v, β learned |
| `r1_fc2.0+fc2.1+fc2.2_r4` | rank-4 updates on all three blocks' `fc2` at once (3,084 parameters; the net has 163,458) |
| `_t<lo>-<hi>` | t-gate: the edit acts only for t ∈ [lo, hi] (t = 1 noise, 0 action); `t0.4-1` = the first 60% of the decode |
| `r1p_<layer>` | rank-1 with v fixed to one global contrast-probe direction; u, β learned |
| `r1pc_<layer>` | one rank-1 per miner cluster, v fixed to that cluster's contrast-probe direction; u, β learned |
| `r1pcg` / `r1pcx` / `r1pcgx` | as `r1pc`, with a one-sided read u·relu(vᵀa+β) (`g`, a 1-unit graft: E1's family) and/or the probe calibrated against good trajectories at every negative's condition (`x`) |
| `abl_<site>` | mean-ablate the global probe direction (`ablate_direction`, side post) |
| `ablc_<site>` | mean-ablate all per-cluster mean-difference directions |
| `_w1-<b>` | loss = (hopB method + 1·vote-masked dist anchor + b·local anchor) / (2 + b); `w1-0` = B1a's loss |
| `_aAML` | the repo's `AML` anchor (local + vote-masked, logged noise) in place of `AMdist` |
| `b1a_trunc_r<k>` | train B1a (all weights), then keep only the top-k singular directions of each weight matrix's change |
| `full_w1-0.5` | control: all weights trained with the `_w1-0.5` loss and B1a's schedule |

## Headline

- **Low-rank, t-gated direction edits match the frozen recipe; they do not beat it.** Rank-4 writes on all
  three `fc2` layers, active for t ∈ [0.4, 1] (3,084 parameters, 1.9% of the network's size), give
  D 0.283 vs B1a 0.281 on k4 and 0.447 vs 0.446 on alt (seeds 0–4, npm 4 and 16), with less mass between modes
  (0.036 vs 0.046; 0.041 vs 0.067). Same loss, same data: the bottleneck is the recipe's data and anchor, not
  the edit's capacity.
- **The decode decides the mode early, and late changes only hurt.** Switching B1a back to π_ref for the last
  30% of the decode (t < 0.3) lowers D in **19 of 20 cells** (−0.004 ± 0.001 k4, −0.009 ± 0.002 alt). A rank-2
  `out` edit active only late (t < 0.5) reaches D 0.454; the same edit early (t ≥ 0.5) reaches 0.234.
- **Directions that separate bad trajectories exist from step 0, but only per failure cluster.** A label-free
  linear probe (bad-basin vs other decodes at matched conditions) reaches AUC 0.64–0.72 with one global
  direction, and 0.95–0.99 per miner cluster already at step 0 in block 0's `fc1` activations.
- **Probe directions make poor edits.** Every edit built on a fixed probe direction (rank-1 write, one-sided
  read, calibrated read) is far worse than a learned read (k4 0.39–0.42, alt 0.52–0.54). Ablating directions
  either does nothing (the global probe direction, D unchanged) or destroys the decode (per-cluster contrast
  directions: off mass 0.73–0.92).
- **Best D on alt: the local anchor.** The rank-4 t-gated edit trained with the repo's local anchor (`AL`)
  gives alt D 0.399 vs B1a 0.446 (9/10 cells, Collateral 0.087 vs 0.295). That gain comes from the loss: the
  repo's full-weight `R_hopB_bsup_neg_AL` gets 0.408 on the same 6 cells (edit 0.394). On k4, `AL` costs
  removal (0.351 vs 0.261).

## Best method and why it works

For k4 and alt together, the best edit is `r1_fc2.0+fc2.1+fc2.2_r4_t0.4-1`: one rank-4 update to each block's
`fc2` (W ← W + Σᵢ uᵢvᵢᵀ plus bias uᵢβᵢ), active only while t ≥ 0.4, fit on the frozen recipe's loss with
π_ref frozen. It ties B1a in D, with lower Collateral and between-mode mass. For alt alone, the same edit with
the `AL` anchor is best (0.399, 9/10 cells below B1a). The cheapest robust improvement found is not an edit of
its own: **gate B1a's change by t** (t ≥ 0.3), which beat B1a in 19/20 cells.

Why it works:
1. *The change the recipe needs is low-rank.* B1a's own weight change has 50–65% of each block matrix's energy
   in 4 singular directions (70–85% in 8). Truncating B1a to rank 8 per matrix keeps its D on k4
   (−0.005 ± 0.003) but loses removal on alt (+0.014 ± 0.004): the rank needed is setting-dependent. A
   learned rank-4 edit fit directly matches full training (`_w1-0.5` vs `full_w1-0.5`: +0.008 ± 0.006 k4,
   +0.004 ± 0.006 alt).
2. *Destinations are fixed early.* The noise decides the mode; the probe separates a cluster's bad trajectories
   at step 0. Steering in the first half of the decode moves a trajectory to a neighbouring basin. Steering
   late drags the action off its mode into the region between modes (off mass rises from 0.03 to 0.10–0.15).
   The t-gate keeps the late, mass-shaping part of π_ref intact.
3. *Multi-layer beats single-layer at equal rank.* Rank 4 spread over three `fc2` layers (D 0.147 on the dev
   cell, ungated) beats rank 16 on one layer (0.167). `out` alone (rank ≤ 2) is too small (0.225).

## Measurements that made the edit easy to design (Phase 4 tool candidates)

1. **Per-cluster contrast AUC by step and layer** (`probe_cluster.py`). It shows that the bad destination is
   linearly readable from step 0 in block 0, and that the right unit of analysis is the miner cluster, not
   the whole forget set. A `contrast(cluster, layer, k)` tool that reports held-out AUC per step would expose
   this directly. Report the global AUC beside it, so an agent sees that one direction does not cover all
   clusters.
2. **A t-window sweep of a candidate edit, with between-mode mass.** The single most useful knob. The tool
   needs no oracle: quick_check's drift and a label-free "atypical action" rate (5-NN distance to π_ref
   samples, as in `targets._typical`) both track the off-mass rise from late edits.
3. **Singular spectrum of a trained change** (`b1a_rank.py`): how much of a fit lives in a few directions per
   layer, and the D of its rank-r truncation. It sizes a rank budget for an edit and shows which layers carry
   the change (on k4 s0 n16 the three `fc1` layers carry 61% of B1a's change energy, the `fc2` layers 28%, the
   time and condition MLPs 11%, `inp` and `out` under 0.2%).
4. **Projection statistics of a probe direction** (variance along v on good vs bad trajectories). The global
   probe direction had sd 0.04 in activation units, which explains why ablating it did nothing.

## What failed

- `ablate_direction` in every form. The global probe direction carries almost no variance (no effect,
  Removed 0.000). Ablating per-cluster mean-difference directions removes mode-identity information all modes
  share, and actions collapse between modes (off 0.73 at `fc2.0`, 0.92 at `out`; D 0.82–0.94). Ablation is not
  a redirect.
- Fixed probe directions as the read vector of a write (`r1p`, `r1pc`, `r1pcg`, `r1pcx`, `r1pcgx`). High
  AUC does not make a good read: AUC measures ranking, while a write needs a response that is near zero on
  every good state at every condition and scales with how far the trajectory must move. Learned reads
  (trained on the recipe loss) win by 0.13 (k4) and 0.10 (alt) in D.
- Ungated edits put mass between modes (off 0.06–0.12 vs 0.03 gated).
- Low-rank truncation of B1a as a method: helps k4 at rank 8, hurts alt at every rank.
- No direction edit beat B1a on k4 by more than noise.
