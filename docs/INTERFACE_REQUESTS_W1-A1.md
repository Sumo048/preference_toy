# Interface requests from W1-A1

1. **W1-A2 (`toyrepair.oracle.purity`)**: the miner calls `oracle.purity(cell, uids) -> float` (majority-mode share of the members). Until it is merged, `miner.purity_of` catches `NotImplementedError` and uses `miner._purity_adapter` (same definition, reads `cell._oracle.neg_modes`). After the merge, delete `_purity_adapter` and the fallback. Purity is written to `purity.csv` only.
2. **W1-B (grafts and `policy.decode` capture)**: `policy.decode(..., capture=...)` records activations with forward hooks on the modules named in `CAPTURE_LAYERS` (`inp`, `blocks.i.fc1/act/fc2`, `blocks.i`, `out_norm`, `out`; `cond` = cat(time_mlp, c_mlp) outputs; `out_act` = SiLU(out_norm)). A graft that wraps a Linear should keep the module at the same path (the hook then captures the post-graft output) and expose the original Linear as `.base` (used by `policy.layers` for sizes); graft modules should have `graft` in their own name and an `n_units` attribute so `layers()` lists them. Alternatively a net may define `forward_capture(x, t, c, names) -> (v, {name: (B, d)})`, which `decode` then uses.
3. **W1-B (`patches`)**: `policy.load_version(run_dir, version_id, cell)` finds the stack by reading `<run_dir>/patches/*.json` and following `parent_version` from `version` back to `v0`, then calls `patches.rebuild`. Each patch JSON must hold the keys `id`, `version`, `parent_version` (as the `Patch` dataclass has).
4. **W1-D / W1-A2 (decode counting)**: `policy.counter` (`DecodeCounter`: `total`, `by_version`, `reset()`) counts every `decode` row as 1 and every `velocity` row as 1/20. The branch tool, `quick_check` and `mine` also return their own decode counts (`BranchTable.n_decodes`, `QuickCheckResult.decodes`, `Atlas.meta["decodes"]`). The budget can read `counter.total` before and after a tool call.
5. **W1-D (CLI)**: the inspect tool is `flowstate.inspect(cell, version, uid, units=[(layer, idx)], every=1) -> InspectTable` (`.render()`, <= 21 rows); the branch tool is `flowstate.branch(cell, version, cluster, steps, M, primitives, seed) -> BranchTable` (`.render()`, <= 40 rows); clusters come from `atlas.cluster_by_id(id)`; the atlas text is `Atlas.render()` (<= 1500 tokens, card <= 150, with a 3.5 chars/token estimate in `miner.est_tokens`; swap in W1-D's measured ratio). `quick_check(...).render()` prints the three numbers.
