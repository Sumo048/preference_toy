2. **Matches toypref:** the decode adapter is bit-identical to `CondFlow.sample`. On cond k4 s0 n4, B0 D = 0.51595, the same as W0's value.
3. **Bootstrap:** the gate statistics depend only on the (ref, current, new) labels. So one resample is a multinomial draw over the 729 joint label categories. This has the same distribution as resampling rows and is about 1,000× faster. A test checks the equivalence.
4. **Collateral:** the gate's test 3 uses the PLAN §2 definition (retained modes + OFF, renormalised). `FinalResult.collateral` is the method-map `retain_tv`; `collateral_plan` has the PLAN value. Both are logged.
5. **Reproducibility (§10.3):** a no-op graft (zero output weights, local adapter) gives bit-identical decodes (max diff 0), and repeated gate checks give identical numbers. Tested on k4 s0 n4, alt s0 n4, k4 s1 n16, and uncond base_k2 s0.
6. **Power (§10.3):** the out-layer noise that raises D by 0.01 has σ = 0.047–0.092. With N_G = 16,384 (20 batches per cell, 4 cells), test 2 rejects that noise 100% of the time. That direction is trivial: a no-op's upper bound is 0, which is not < 0. The informative direction is with current = noisy and new = π_ref, a true 0.01 improvement. There test 2 passes 100% at N_G 16,384, 75–85% at 4,096, and 25–40% at 2,048. **N_G needed: 16,384 (keep the default); 8,192 is likely the minimum.**
7. **Gate CPU time per check** (1 thread, N_G 16,384): 2.8 s cond and 2.4 s uncond, with π_ref == current (2 decodes of the batch). About 3.9 s with 3 decodes. The bootstrap takes under 0.1 s. Loading a cond cell takes 43 s (the 200k pool decode).
